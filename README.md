## Orion — a family of focused .NET libraries

Small, single-purpose, production-shaped building blocks for distributed .NET systems. Each is standalone and independently versioned.

| Library | Description |
| --- | --- |
| [OrionGuard](https://github.com/tunahanaliozturk/orionguard) | Comprehensive guard-clause & validation ecosystem for .NET |
| [OrionSaga](https://github.com/tunahanaliozturk/orionsaga) | In-process saga orchestration with automatic compensation |
| [OrionPatch](https://github.com/tunahanaliozturk/orionpatch) | Transactional outbox — enqueue in SaveChanges, dispatch at-least-once |
| [OrionLock](https://github.com/tunahanaliozturk/orionlock) | Backend-agnostic distributed locking (Redis / EF Core) with lease renewal |
| [OrionAudit](https://github.com/tunahanaliozturk/orionaudit) | EF Core audit trail: JSON-Patch diffs, multi-tenant, time-travel |
| [OrionOnce](https://github.com/tunahanaliozturk/oriononce) | HTTP idempotency middleware for ASP.NET Core |
| [OrionRelay](https://github.com/tunahanaliozturk/orionrelay) | Outbound webhook delivery — HMAC signing, backoff with jitter |
| [OrionBeacon](https://github.com/tunahanaliozturk/orionbeacon) | Leader election with renewable leases and fencing tokens |
| [OrionVault](https://github.com/tunahanaliozturk/orionvault) | Column-level transparent encryption at rest for EF Core |
| [OrionStream](https://github.com/tunahanaliozturk/orionstream) | Topic-based Server-Sent Events hub for ASP.NET Core |

<sub>Also OrionGrant · OrionLedger · OrionShade · OrionLens · OrionKey — and [OrionShowcase](https://github.com/tunahanaliozturk/orionshowcase), a production-shaped banking sample wiring the family together.</sub>
